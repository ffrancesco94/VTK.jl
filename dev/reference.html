API reference ​

The supported high-level API is documented below. Generated raw VTK methods remain lower-level bindings and do not acquire the high-level ownership and diagnostics guarantees merely because they are registered.

Particle tracing is quarantined under VTK.Experimental.particle_tracer. Its execution path is unsupported until the static-grid crash and temporal pipeline behavior have been validated; use stream_tracer for static fields.

VTK.Experimental.particle_tracer Function
julia
Experimental.particle_tracer(args...; kwargs...)

Unvalidated particle-tracer execution. This API is explicitly experimental: the static-grid crash is unresolved and no temporal execution path is advertised. Use VTK.stream_tracer for static vector fields.

VTK.checked_output Method
julia
checked_output(algo; operation=:Update, filename=nothing) -> owning output

Call the raw GetOutput(algo) and return its owning vtkDataObject smart pointer. A null result or native take_ref failure is converted to VTKError with operation, algorithm class, optional filename, status 0, and an error diagnostic containing the native detail. operation accepts a symbol or string.

No points, cells, or other dataset-cardinality checks are performed: a non-null empty dataset is a successful output. The raw GetOutput binding is unchanged.

VTK.downcast Method
julia
downcast(obj) -> typed grid or vtkDataObject

Recover the nearest registered grid type from a generic vtkDataObject. Derived VTK classes are recognized through IsA. An unregistered class is returned as an owning generic vtkDataObject handle. Null objects and invalid forced downcasts are errors; a non-null dataset with zero points/cells is not.

source
VTK.drain_vtk_deletions Method
julia
drain_vtk_deletions(; force=false) -> Int

Destroy queued VTK smart-pointer wrappers at a quiescent point and return the number drained. With one Julia thread this is safe at ordinary call boundaries and is also done automatically at high-level operation/factory entry points.

With multiple Julia threads, another task or raw binding call may be inside VTK even when no high-level operation is running. Consequently the default call throws. Use force=true only after all tasks and native threads using VTK have finished and no other VTK call can start until draining returns. Raw-only workloads use this function for reclamation in both threading modes.

VTK.refresh! Method
julia
refresh!(a::VTKDataArray)

Rebuild the cached zero-copy view from the underlying VTK array and record its current structural signature. VTK.sample_over_line Method
julia
sample_over_line(grid, p1, p2; resolution=100, scalars=nothing) -> vtkDataSet

Sample a dataset along a line from p1 to p2 with resolution points. Returns a dataset with the sampled values. This is the VTK equivalent of ParaView's "Plot Over Line".

scalars may be one point- or cell-data array name, or a collection of names, to retain only those sampled arrays. Every selected name must exist in the source. vtkValidPointMask is always retained. By default all arrays are passed through. Array selection never modifies the source dataset.

Example

julia
profile = VTK.sample_over_line(grid, (0.5, 0.5, 0.0), (0.5, 0.5, 1.0); resolution=50)

VTK.update_with_diagnostics Method
julia
update_with_diagnostics(algo; filename=nothing, operation=:Update)

Execute algo with a fresh scoped observer and return a named tuple with status, diagnostics, operation, algorithm, and filename fields. diagnostics contains every error, warning, text, and debug record in emission order. Update uses status 1 when no error was captured and 0 otherwise.

This inspection variant does not log diagnostics or throw for VTK error events or a zero status; use update! for the checked form. Native argument and binding errors still throw. Concurrent mutation/execution of the same VTK algorithm is unsupported.

VTK.@vtk_filter Macro
julia
@vtk_filter(name(args..., Factory → output; kwargs...) begin ... end)

Generate a standard VTK filter wrapper function. The config block has access to f (the filter object), all positional arguments, and all keyword arguments.

Examples

julia
# Single input, no extra configuration
@vtk_filter cell_to_point(grid, CellDataToPointData → pass_through) begin
    # no extra configuration
end

# Two positional args, with kwargs and a fixed output type
@vtk_filter clip(grid, implicitfn, TableBasedClipDataSet → vtkUnstructuredGrid;
                insideout=false) begin
    SetClipFunction(f, implicitfn)
    SetInsideOut(f, insideout)
end

# Fixed output type, with kwargs
@vtk_filter contour(grid, values, ContourFilter → vtkPolyData;
                   scalars=nothing) begin
    scalars === nothing || SetInputArrayToProcess(
        _cp(vtkAlgorithm, f), 0, 0, 0, 0, String(scalars))
    for (i, v) in enumerate(values)
        SetContourValue(f, i - 1, v)
    end
end
