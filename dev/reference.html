VTK.VTKDataArray Type
julia
VTKDataArray{T} <: AbstractMatrix{T}

Typed, zero-copy view of a VTK data array with ncomponents columns and ntuples rows... i.e. size is (ncomponents, ntuples) (component-fastest, matching VTK's AOS storage). Construct from any wrapped array object with VTKDataArray(obj) (the element type is discovered from the array), or create a new array with data_array(T, ncomponents).

VTK.data Method
julia
data(da) -> VTKDataArray{T}

Owning, typed, zero-copy (ncomponents, ntuples) view of the array storage. Holds the underlying smart pointer, so it (and views derived from it, e.g. vec) stay valid after the original handle is dropped.

VTK.raw_data Method
julia
raw_data(da) -> AbstractVector

Zero-copy flat view of the array storage (component-fastest, length ncomponents * ntuples). The element type matches the array's storage type. The view is derived from an owning VTKDataArray wrapper, so the underlying storage stays alive as long as the view does — the owner may be dropped.

julia
read_vtm(path) -> vtkMultiBlockDataSet

Read a multiblock XML file (.vtm, a container referencing .vtu/.vtp/ … blocks). Access blocks with nblocks/block(mb, i); each block is a borrowed view — keep the multiblock dataset alive while using them.
